About TagForge

TagForge is a browser-based tool for creating professional Minecraft server tags, badges, and rank icons.

Features

  • Pixel-perfect rendering for small Minecraft tags
  • Transparent PNG export with alpha channel
  • Minecraft color codes support
  • Gradient text effects
  • Glow, shadow, and outline effects
  • Custom icon support
  • ItemsAdder compatible export
  • Save/load projects with localStorage
  • Export/import as JSON
  • Mobile responsive design

How to Use

  1. Edit your tag text and styling in the editor
  2. Preview the result in real-time on the canvas
  3. Choose your desired canvas size
  4. Export as PNG at 1x, 2x, or 4x scale
  5. Use the exported PNG in your Minecraft resource pack

ItemsAdder Integration

Click "Generate ItemsAdder Config" to create a configuration snippet for ItemsAdder. Enter your namespace and texture name, then copy the generated YAML.

Privacy

All processing happens locally in your browser. No images or data are sent to any server.
